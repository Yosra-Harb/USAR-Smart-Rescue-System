# Phase 4: Spatial Bayesian Localization and Rescue Planning

## 1. لماذا تغيّر النموذج؟

كان نموذج v3 قويًا في تراكم الدليل، لكنه كان يستقبل شدة قياس واحدة لكل
حساس. عدة خلايا قد تفسر الشدة نفسها، لذلك يصبح posterior حساسًا للبذرة
العشوائية عند توسيع عدد السيناريوهات. v4 يضيف هندسة القياس نفسها.

## 2. معادلة التوطين

لكل خلية مرشحة \(x\) وحساس \(s\):

\[
B_s(x)=(1-P_{D,s}(x)) + P_{D,s}(x)
\sum_j \frac{g_s(z_j\mid x)}{\kappa_s(z_j)}
\]

حيث:

- \(P_D\): احتمال الكشف المتوقع من المدى والركام والضوضاء والحجب.
- \(g\): Gaussian likelihood لبواقي المدى والزاوية مع عدم يقين القياس.
- \(\kappa\): كثافة clutter المنتظمة في مجال القياس.

ويُحدّث Log-Odds بعد tempering لمنع الثقة الزائدة. المسار لا يُؤكد إلا
بعد مشاهدات مستقلة مكانيًا، ولا تُعاد القمة التاريخية كتجربة جديدة.

## 3. حدود تسرب الحقيقة المرجعية

`generateSpatialObservations` وطبقة SensorSimulation فقط تستطيعان قراءة
مواقع الضحايا لتوليد قياس noisy. بعد `buildMeasurementPacket` لا توجد
حقول victim ID أو true position أو true range/bearing. دوال likelihood
تقرأ خرائط البيئة المرصودة والقياسات فقط.

## 4. تخطيط الإنقاذ

ينتج `planRescueRoute` مسارين:

1. **Shortest:** تكلفة الخطوة هي طولها الهندسي فقط.
2. **Recommended:**

\[
c = d\,[1+w_D D+w_R R+w_A(1-A)]
\]

حيث \(D\) الركام، \(R\) الخطر، و\(A\) سهولة المرور. العوائق مغلقة،
والحركة القطرية لا تقطع الزوايا. إذا كانت خلية الضحية نفسها مغلقة، يخطط
النظام إلى أقرب نقطة وصول ضمن `goalAccessRadius`.

## 5. أولوية الإنقاذ

`medicalSeverity = 1 - vitalityIndex`. الدرجة تجمع الخطورة الطبية،
قابلية الوصول، القرب، سهولة المسار، وأمانه. يوجد حد تفاعل
`severity × reachable × accessibility × safety` ليحقق مطلب أن الضحية
الأكثر خطورة والتي يسهل الوصول إليها تحصل على الأولوية الأعلى.

الأوزان مركزية في `Utilities/constants.m` وقابلة للتجميد بعد المعايرة.

## 6. بروتوكول التقييم

`runGeneralizationEvaluation([10 5 5])` ينشئ 120 تشغيلًا منفصلًا:

- Calibration: البذور 1–10 لكل نوع.
- Validation: البذور 1001–1005 لكل نوع.
- FinalTest: البذور 2001–2005 لكل نوع.

لا يجوز تعديل المعاملات بعد الاطلاع على FinalTest. تحفظ الدالة النتائج
الخام، ملخص كل سيناريو، ومتوسطات وفواصل ثقة 95%.
