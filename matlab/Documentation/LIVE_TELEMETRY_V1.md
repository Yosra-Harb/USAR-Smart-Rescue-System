# USAR Live Telemetry v1\n\nThis increment adds append-only `telemetry.jsonl` streaming without changing sensor, fusion, localization, vitality, priority, or rescue-planning equations.\n\n## Contract\n\n- `MISSION_STARTED` is sequence 0.\n- Every completed inference cycle writes `STEP` or `VICTIM_CONFIRMED`.\n- `MISSION_COMPLETED` is appended after final results are built.\n- The telemetry contract explicitly sets `containsGroundTruth=false`.\n- Oracle/diagnostic sensor fields are not exported.\n- Final evaluation Ground Truth remains isolated in `evaluation.json`.\n\n## Reliability choice\n\nThe file is opened in append mode and closed after every record. This is intentionally conservative for an outage-prone environment: already-written JSONL records remain readable if a later MATLAB cycle is interrupted.\n
